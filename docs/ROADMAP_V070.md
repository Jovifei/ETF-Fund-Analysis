# v0.7.0 预测走廊与因子验证路线

## 已实现

1. 保留相似样本模型为基线，并使用按期限区分的高级技术特征。
2. 标签同时覆盖终点收益、未来路径最低收益和最高收益。
3. 输出终点收盘区间、路径支撑/压力区、走廊位置和触及概率。
4. 使用研究级局部残差扩张；明确不是正式 MAPIE 校准，状态保持 not_calibrated。
5. 内建 Alphalens 风格 IC/Rank IC/ICIR/分位收益/换手/主题和市场状态诊断。
6. 提供可选 LightGBM/CatBoost 全局模型 holdout 基准。
7. 预留 MAPIE、MLForecast、AKQuant、Qlib、Riskfolio、RQAlpha 等隔离研究依赖。

## 晋升条件

- 数据源资格通过；
- 真实 ETF 池至少五年数据；
- 时间序列 Train/Rolling/Holdout；
- 80%与90%区间覆盖率和宽度达到预设标准；
- 相比相似样本基线有稳定增量；
- 第二回测引擎误差可解释；
- 至少20个交易日影子运行；
- 人工批准。
