# ETF-20261126-01 修复 ETF 邮件和行情调用超时

## 原因与改动

邮件的 slim 抽取遗漏了原包中的 `structure_v1`，导致威科夫、道氏与 ATR 风险桶显示占位。抽取器现在沿用行、详情、sidecar 的字段优先级。命令行加载 sidecar 内容，按标的和观察日精确匹配。缺数据时保留原有缺失状态，ATR 风险桶仍使用原包的研究口径。

11:40、14:30、14:45 的策略邮件要求 G1–G7 均明确通过。缺项或非布尔结果输出未就绪状态。收盘复核收到损坏或空的闸门报告时也输出未就绪。行情 SDK 以单调时钟计算总预算，子进程启动计入预算，超时时直接回收进程。

## 影响与验收

Jovi 已授权以当前生产者 `29fe6e3` 为基底发布独立修复。此基底包含本机产包时钟修正。正式发布将绑定精确 Git 提交并复跑全量。

变更涉及邮件抽取、策略邮件闸门和行情 SDK 超时。以 `29fe6e3520d83cbd9a2b33e71cd86e21c16ef550` 为基底的候选树 `dce5eee5ea0e50e3f7c6c4e33438a2cf33357ac8` 已通过 113 项专项、Python 编译及 JS 语法检查。合成渲染的 4 张 PNG 与 4 个 HTML CID 和本地 MIME 图片逐一对应。

上一候选全量回归 3098 项通过、25 项跳过、1 项失败。数据访问子进程硬超时测试在全量耗时 5.47 秒，超过 5 秒上限。新候选全量 3113 项通过、25 项跳过、零失败，退出码 0。硬超时用例新全量耗时 0.281 秒。

同一事故的产包时钟补丁及旧版复现收据保存在项目的 `.delivery-validation/etf-incident-20261126-29fe6e3/`。部署、同槽网站读回、正式 MIME 与 Gmail 投递仍待验收。

## 回退

回退点为变更前的版本和已留存的排程、接收镜像与数据库备份。回退会恢复此前邮件显示和行情 SDK 等待行为。正式采用后如需回退，按发布记录恢复对应版本，并用当日同槽合格批次验收。
