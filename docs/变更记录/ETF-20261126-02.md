# ETF-20261126-02 修正工作区浏览器测试入口

## 原因与改动

决策矩阵默认展示原生表格，旧的浏览器测试仍等待默认加载嵌入板。设置页将行情接入、模型配置和成员管理放在各自的页签，直接打开旧入口无法触达控件。

冒烟和响应式用例先检查当前默认界面，需要测试嵌入板时从「原版嵌入视图」打开。设置相关用例通过现行页签完成相同的后台任务入队、加密保存和账户管理操作。保留筛选、研究期限、导航、图表、无横向溢出和权限断言。
