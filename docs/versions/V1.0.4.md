## 数据、算法与凭据边界

ETF行情契约仍 `cn-fund-shares-cny-v1.0.1`；指数缓存仍 `index-ohlc-v103`。新增研究版本 `price-similarity-research-v104-1-5-20`，不冒充 canonical current action，不自动 calibrated/actionable。周/月图指标使用同一服务端公式按该周期重新计算。
API配置AES-GCM加密，外部主密钥不在数据库；Windows CurrentUser DPAPI、Unix私有目录/600文件。主密钥丢失则旧Key无法解密，备份数据库必须另行保护密钥备份。支持明确的 OpenAI-compatible Chat Completions；非兼容厂商专用协议不假装可用。模型API与Codex订阅账户不同。
