# V1.0.7 — Recompute public unit evidence

## Change

- Corrects the Sina runtime observation contract to the units observed in the
  current response and reconciled against Tencent; the documented label
  conflict remains visible in the audit note.
- Allows bounded relative rounding differences for large public-source values
  while retaining strict absolute tolerances for small values.
- Recomputes existing evidence rows when the contract result changes instead
  of reusing stale uncertified rows.
- Bumps the data contract to
  `cn-fund-shares-cny-v1.0.7-sina-recompute`.

## Boundary

Price-only stored bars remain uncertified even when raw cross-source
observations exist. Realtime, PIT/OOS, calibration, and actionable gates are
unchanged.
