# V1.0.6 — Tencent public daily evidence path

## Change

- Adds a bounded AKShare Tencent daily-history adapter using
  `stock_zh_a_hist_tx` as an independent public source.
- Preserves Sina raw volume/amount fields for same-day evidence comparison
  without turning a price-only stored bar into a qualified bar.
- Binds certification to the stored bar's non-null quantity values and exact
  quality hash; mismatches remain rejected.
- Bumps the data contract to
  `cn-fund-shares-cny-v1.0.6-tencent-unit-evidence`.

## Boundary

This release can create evidence only when both source observations, the
stored bar, and the requested date range pass the existing gates. It does not
qualify realtime timestamps, PIT/OOS history, forecast calibration, or
actionable decisions.

## Verification

Backend pytest, compileall, Node checks/tests, Vue tests, typecheck, and the
production frontend build passed in the isolated worktree. Production refresh
and certification remain a separate deployment receipt.
