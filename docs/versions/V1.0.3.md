## 第一批：历史可看不等于可操作

- 共用计算改为逐标的历史资格隔离：缺量/旧单位/多复权口径不阻断其他标的；全局验证和回测仍严格阻断。
- 历史 OHLC 可独立生成 MA/MACD/KDJ/RSI 等价格指标，缺成交量不填入展示；不生成新的五档动作、不继承不合格预测。
- 缺报价时详情使用明确标记的历史收盘价，不写入实时行情表。原版总览模板展示历史指标解释和数据日期。
- 原图表、模板和数据单位不变。源采集失败保留旧价格的日期，任务仍报告 partial。
