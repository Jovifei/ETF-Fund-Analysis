## 一、本次更新核心内容

根据第二版独立审核报告（`ETF_FACTOR_EMPIRICAL_INDEPENDENT_AUDIT_20261024.md`）提出的各项实质性缺陷，本版本进行了深度治理与全量实证重算：

### 1. 资金预算约束与等权基准（B0）回撤根除
- **缺陷治理**：原实现赋予每只资产 1.0 独立权重并在模拟器中求和，造成 $N$ 倍杠杆敞口，使等权基准出现 $-173.6\%$ 的虚假爆炸回撤。
- **治理实现**：
  - 在 `simulate_portfolio_ledger_daily` 中强制施加组合总预算约束 $\sum w_i \le 1.0$。
  - 等权基准（B0）在每日 $t$ 严格按照可用标的数计算等权权重 $w_i = 1 / N_t$，未分配资金全额留存现金（日息 0.0）。
  - M2 波动目标同样受到 $\sum w_i \le 1.0$ 预算限制。
- **重算结果**：B0 最大回撤恢复至正常区间（Holdout 2Y 为 **`-13.2%`**，扣费净夏普 `+0.780`；Recent All 为 **`-20.4%`**，扣费净夏普 `+0.647`）。

### 2. 加仓、减仓真实入账与摩擦计费
- **缺陷治理**：原实现仅按 $\min(old, new)$ 估算持仓，遗漏了加仓/减仓过程中的订单执行、手续费扣除及当期收益。
- **治理实现**：
  - 建立统一的开盘执行订单撮合引擎：
    1. **隔夜跳空**：在手持仓首先计入 $Close_t \to Open_{t+1}$ 价格变动。
    2. **开盘先平/减仓**：按 $Open_{t+1}$ 成交卖出，回笼现金并扣减手续费：$\text{Cash} += \text{TradeAmount} \times (1 - \text{fee})$。
    3. **开盘后建/加仓**：按 $Open_{t+1}$ 成交买入，支付资金并扣除手续费：$\text{Cash} -= \text{TradeAmount} \times (1 + \text{fee})$。
    4. **日内损益结算**：调整后持仓计入 $Open_{t+1} \to Close_{t+1}$ 价格变动。
  - 摩擦费率按单边 10 bps（往返 20 bps，0.0010/单边）精确扣除。
- **对账单测**：新增 `test_position_adjustment_fees_and_intraday_accrual`，手算验证平价从 10% 加到 20% 时收取约 1 bp 组合费用并精确反映日内损益。

### 3. 日净值与逐笔账本算法统一
- 消除“日净值用减法、逐笔账本用乘除”的双轨脱节。全系统统一调用共享的 `simulate_portfolio_ledger_daily` 引擎。
- 净值从 100,000 元（1.0）开始，每日净值严格等于现金余额加上全部持仓市值，破产（净值 $\le 0$）即刻终止并不允许复活。

### 4. 前瞻多日收益窗口纠偏与单脉冲回归
- $h$ 日前瞻复合收益严格取自未来第 1 至第 $h$ 天（`shift(-1)`）。
- 新增 `test_forward_return_single_pulse_and_varying_series`，通过单脉冲突跳（+10%）和非恒定收益序列严格验证窗口对齐与尾端截断逻辑。

### 5. 训练集边界 Purging 与样本外定性
- **边界 Purging**：在 `run_audited_momentum_validation.py` 中，训练集末尾清洗跨入验证期的多日重叠前瞻标签（缓冲期 $1.5 \times h$ 天），防止前瞻泄漏。
- **样本外定性**：明确声明 Holdout 2Y 已被多次用于策略对比，正式定性为**开发验证集（Validation Set）**，非全新盲测集；必须等待未来未见序列向前推进（Walk-forward）积累。
- **统计有效性**：声明普通 Wilson 区间在多日重叠与标的相关下仅代表**描述性不确定度区间**，不单独作为 Alpha 显著性证明。

### 6. 报告文字与数据硬矛盾消除
- 动态联动实测数据生成报告：
  - **C0 / C1 公平对照**：C0（`mom_120_cs`）净夏普 `+0.317`、净回撤 `-52.8%`；C1（`dual_momentum_c1`）在相同 Top-4 候选下叠加绝对动量门控，净夏普 `-0.077`、净回撤 **`-37.3%`**。如实评述门控收敛回撤但在震荡期产生现金拖累的机理。
  - **`z_mr_20` IC 纠偏**：如实反映纠偏后的真实 IC（留出期 `-0.0893`、训练期 `-0.0154`、近期 `-0.0152`），正文明确其在各切片夏普为负（`-1.101`），不具备作为主买卖信号资格。

### 7. CI 门禁与依赖安全升级
- 修复 `workspace-ci` Playwright E2E 超时问题：周期选择由不存在的选项 `'5'` 对齐为标准合同选项 `'7'`（`bea01df`）。
- 升级 `vite@7.3.7` 与 `vitest@4.1.12`，彻底消除安全审计高危漏洞阻断（`ac8a1e0`）。
