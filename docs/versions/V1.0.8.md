# V1.0.8 — Public amount rounding tolerance

The public Sina/Tencent amount comparison now permits a bounded relative
rounding difference of `1e-5` for large values while retaining the existing
`0.5 CNY` absolute floor. Small-value mismatches and factor errors remain
rejected. The data contract is
`cn-fund-shares-cny-v1.0.8-public-rounding`.
