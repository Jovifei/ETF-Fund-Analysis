# v1.0.2 统一总览修复记录

基线：codex/v1.0.1-data-access / 127ee3d0c8bb572af87c4e1cf906fec564a74e63。2026-09-08 核实 main 仍为 3c7bdc7。此分支不覆盖 main、不改写旧分支、不部署生产。

## 代码审查发现

1. frontend/src/views/Overview.vue 仅有简化决策表；完整旧模板被放在 /classic/etf-board，Matrix 又是一套并列页面。用户要求完整原模板就在总览的 ETF 决策快照位置。
2. frontend/src/components/Login.vue 没有注册入口，但后端已有邀请注册和管理员用户管理 API。不能让创建用户必须跳去旧看板。
3. catalog.py 的 Tushare 目录按名称 ETF/LOF 分类，漏掉没有这些字样的产品；AKShare 目录依赖东财现价接口，超时无目录后备。搜索无分页总数。
4. 行业/概念采集和 SectorSnapshot 已存在，不应另造数据层。Overview 在快照为空时会隐藏板块；采集空结果可能报告成功，零涨跌使用 or 表达式丢失。
5. 新 worker 只运行手动任务，安装完成并不自动拥有证券目录和板块快照。需显式的发现任务和可选低频调度，GET 不得采集。

## 必须保留

同一 Vue 外壳、同一首页 /、原 decision_board_workbuddy.html/CSS/JS 显示模板与五档分组；仅调整嵌入宿主、身份和路由，不重做简化模板。点击 ETF 进入 /etf/{ts_code}，返回恢复筛选。旧地址归一到首页快照位置。登录不展示市场表；注册沿用邀请码门禁；已有管理员可在页面创建成员。保留全部 Provider Adapter、账户、持仓、指标、支撑压力与 1/3/5/10 预测合同。
