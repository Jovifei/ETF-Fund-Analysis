## 一、本次更新核心内容

来源：独立代码审查 `1a4b665..8e062b7`（记录见 `docs/audits/CODE_REVIEW_1A4B665_8E062B7_20261025.md`）。4 项 Important、6 项 Minor 全部修复，先失败测试后实现。

### 1. 展示包报价新鲜度：单一权威
- 新增 `bundle_expired` / `bundle_is_stale` / `quote_display_state`（`backend/app/workspace/local_display_read.py`）。
- 整包有效期（2 小时）与单报价源龄（600 秒）是两个独立事实，以前分别由详情页和自选/持仓定价各自解释，周末必然互相矛盾。
- 现在详情页、自选、搜索、持仓定价全部走同一判据；详情页首次按源龄降级，`is_realtime` 不会在过期报价上为真。
- 缺 `expires_at` 或不可解析时 fail-closed 返回 stale，不再抛 `KeyError`。`read_instrument_detail` 增加只读 `now` 注入（与 `read_market_context_view` 同惯例）供确定性测试。

### 2. 缺失数据的原因可区分
- local_bundle 模式 404 细分为：`local_display_generation_unavailable`（指定批次不可用）、`local_bundle_unavailable`（无批次）、`local_display_instrument_not_published`（批次未覆盖该代码）。
- 持仓中批次未覆盖的行 grade 由「数据异常」改为「无快照」，并附 `snapshot_available`；board 级 grade 分类不变。
- 自选返回行级 `unpriced_reason`（`not_published_in_bundle` / `no_quote`），页面显示「本批次未覆盖 / 暂无报价」。

### 3. 展示包身份治理（部署门禁）
- 新增 `config/bundle_identity_registry.json`：当前唯一批准生产者 `dcffa8e…` / `041a1286…`，`1a4b665` 标记为 superseded。
- 新增 `backend/app/workspace/bundle_identity.py` 与 `scripts/check_bundle_identity.py`：部署前校验 ECS 的 `SHADOW_SYNC_CODE_SHA`/`CONFIG_HASH` 必须是已登记生产者（exit 0=approved）。
- 新增 `docs/BUNDLE_IDENTITY_AND_WEEKEND_RUNBOOK.md`：身份推进流程、周末 board-only 发布、空网站排障顺序、禁止事项。
- 应用版本与生产者身份保持解耦（网站发布不得作废既有包），本次 env 身份逐项不变。

### 4. 运维可观测性
- `scripts/run_local_compute.py` 新增 `emit_exit`：非零退出在 stdout 末行打印 `{"exit_code":N,"status":"failed"}`，防止 `| tail` 一类管道掩盖退出码。
- 展示读取行对象逐行浅拷贝；market-context 读取显式剔除 `items` 而非 `pop`。

### 5. 版本纪律
- `pyproject.toml`、`app_version`、`frontend/package.json`、`package-lock.json` 统一 **1.0.12**；`test_release_version` 继续以 CHANGELOG 最新节锁定。
- CHANGELOG 补录 `[1.0.11]`、`[1.0.10]` 两节，如实标注来源与发布事实（1.0.10 内容早已在 1.0.9 镜像树中、未单独以该版本号部署；1.0.11 的 `strategy_evaluation` 研究库首次随本版上生产且无运行时调用方）。
