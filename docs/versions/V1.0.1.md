# V1.0.1

发布日期：2026-09-07。

## 发布内容

- 新增 `GET /api/workspace/data-sources`：只返回有效 Provider、依赖、配置和资格前置状态；不发起网络调用，不回显 Tushare Token。
- 新增 `scripts/initialize_local_market_data.py`：只允许仓库外 SQLite、1–3 只 ETF/LOF、非 Mock Provider；使用现有 `WorkspaceDataJob → TaskService` 入库、指标、预测、quote、信号与决策快照链路。
- 初始化命令禁用 Mock fallback、scheduler 与模型调用，并以 Alembic 建立独立本地数据库。

## 数据源资格

- AKShare：本机有界资格检查取得 5 条目录样本；`510300.SH`、`512480.SH` 各 262 根一年日线，OHLC、未来日期、重复日期、成交量和成交额检查均为 0 违规。东财日线出现连接失败时 Adapter 回退 Sina；落库来源保留为 `akshare`，不宣称单一上游稳定可用。新闻本次返回 153 条，仅证明接口可读。
- AKShare quote：20 秒预算超时；实际三标的初始化写入的 quote 均明确 `is_realtime=false` 且带未资格原因。资格报告 `actionable_count=0`，不能产生盘中操作级结论。
- 本地初始化：独立 SQLite 中 `510300.SH`、`512480.SH`、`159928.SZ` 各有 281 根日线，最新日线为 2026-09-04；受限 job 成功完成指标 3 条、预测 12 条、quote 3 条、信号和决策快照。没有启动 scheduler 或模型。
- Tushare：代码支持目录、日线、实时候选、新闻和交易日历；是否能接入取决于独立受控 Token、账户权限和真实资格检查。本版本不迁移、读取或回显任何既有 Token。
- FTShare：保持 disabled/unqualified，不能进入 Provider 链。
- RSS：未配置受信来源时保持 not_configured。

资格证据保存在仓库外的本地运行目录；它不包含在 Git 版本中，也不是生产数据源持续可用或收益资格证明。
