# V1.0.1 — 后端数据接入与原 ETF 指标总表

基线：`codex/v1.0.0` / `9a0ca1812eda24acc390f1b3097662bfd615dfef`。
本轮开发分支：`feat/v1.0.1-data-access`。应用版本 1.0.1；本文件不表示已合并 main、创建 release/tag 或部署用户机器/ECS。

## 改动

- Tushare 固定 HTTPS 传输、显式实时源时间字段、沪市 topic、按交易所批量请求；日线统一 shares/CNY；30/60 分钟 `etf_mins` 适配及任务接线，默认关闭。
- AKShare 实际 SDK 调用放进有截止时间、响应上限、可回收的子进程。ETF-only 查询不再拉整个 LOF 现价。空东财日线也能走 Sina 价格回退；Sina 成交量单位没有独立验证，暂留空，不能伪称量价齐全。
- RSS 可接在显式单数据源模式上；缺失发布时间不填“现在”，UTC 元组正确换算，限制源数量/字节/耗时，日志不回显地址或异常原文。
- 行情、现价、目录、新闻、市场上下文、分钟线任务分离。核心快照先发布，不在每次普通行情任务里抓全目录。真实目录同步修复审计 run_id 漏传。
- 管理员 `/api/workspace/data-sources` 只读呈现有效 provider、凭据存在性、依赖、权限边界、入库覆盖、旧单位待修复状态；GET 不探测网络、不写默认配置。
- 保留 `/classic/etf-board` 原 HTML/JS；Vue 新增 `/matrix` 完整 ETF 横向指标总表，复用同一快照和 `/etf/{code}`。
- 新增持久、认证开启、仅回环的 `run_workspace_live.py`，与临时 Mock demo 分离。Compose 转发 Tushare/AKShare/RSS/分钟配置，旧 scheduler 需显式 profile，避免初始两套采集同时启动。
- 修复 demo 退出前关闭数据库连接，降低 Windows 临时文件占用错误。

## 数据口径/研究资格

数据契约版本为 `cn-fund-shares-cny-v1.0.1`，写入 strategy 配置并参与 config_hash。没有修改指标公式/阈值或唯一五档动作。日线来源有 `:v101` 版本标记，新数据产生新输入哈希。
旧 `akshare`、`tushare`、`tushare:fund_daily` 日线要求按已有最早日期完整重抓；仅当旧日期/复权键全部覆盖，才逐标的原子替换。失败保留原数据并阻断新的衍生结果。旧图暂显示价格，量能/指标/SR 不混用。不要对旧数据库直接执行 volume*=100。

Mock 仍 actionable=false；真实公共现价不可默认标实时；Tushare Token 存在不证明 fund_daily、rt_etf_k、etf_mins 或新闻权限。FTShare 的 enabled/qualified 双门禁不变。本版不自动校准、不自动下单。
