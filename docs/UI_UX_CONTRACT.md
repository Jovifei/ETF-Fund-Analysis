2026-09-06，planning-v1。**目标设计，不是已部署页面。** 旧版归档见 [原UI合同](https://github.com/Jovifei/ETF-Fund-Analysis/blob/3c7bdc7ff36b3dea482651e087127a33c4974903/docs/UI_UX_CONTRACT.md)。实现步骤见 [总方案](planning/ETF_WORKSPACE_VNEXT.md)。

## 1. 参考优先级

最新用户截图是左侧栏/顶部搜索/底部账户的直接需求来源；KairoTrend 官网用于产品参考，本轮没有读取到其已登录应用的动效，因此以下尺寸、色值、动效是**我们的设计建议**，不是其原CSS或实测参数。只借鉴布局与交互，不复制品牌、Logo、付费套餐、邀请返佣或个人信息。

Kairo 决定壳层；tick-stock-panel 借鉴行情卡、可折叠分组、数值密度、因子页；WorkBuddy 留作表格分组/解释密度参考；fund-analysis-matrix 留作早期暗色卡片来源。不存在必须全盘照抄某项目技术栈的要求。

## 4. 顶部搜索是动作选择器

按代码/基金名检索；中文别名可分期实现。证券目录是全市场元数据，持续计算池是自选/重点池，两者不绑定。结果包含代码、名称、交易所、品类、主题、数据资格，不只返回当前已研究的少数ETF。

同一条结果四个动作：**查看数据看板、加入自选、录入持仓、发起AI分析**。查看不写库；加入自选使用现有幂等写接口；持仓必须填写/确认成本和份额；AI只建立草稿，确认provider/数据范围/预算后才运行。一次点击不能隐式同时完成四件事。未初始化标的显示“目录已识别，行情待同步”，不是“该基金不存在”。

建议输入防抖250ms、取消过期请求；上下键/Enter/Esc和键盘焦点可用，搜索框明确标签。Ctrl/Cmd+点击详情保持新页行为。不要用搜索文本拼接Shell、模型URL或SQL。

## 5. 各页组件与数据语义

**总览**：市场环境卡、行业/概念强弱、ETF表、五档计数、1/3/5/10研究期限、来源/时间/覆盖率。目录有N只并不代表N只有合格预测。板块行情与ETF代理涨跌分别标注。默认不对全市场逐只运行LLM。

**数据看板/ETF详情**：身份与现价、日期/资格、权威动作；历史K线与未来情景明确分区；缩放/平移/复位/十字光标；日K及有资格的分钟周期；S/R半透明区和上下界；MA/MACD/KDJ/RSI/TD9等数值、周期、参数版本、解释；预测卡；相关新闻；本人持仓成本线。无数据不填0；无分钟源不以日K替代；单选指标模式和多选图层语义分开。

**AI分析**：无AI空态仍可读确定性指标；单provider任务选择、连接设置、输入证据预览、隐私授权、预算、开始/取消、进度；事实/推断/争议/反证/失效条件与引用；模型意见与系统动作不一致时并列呈现，不覆盖current action。结构化证据比仅发一张图给AI更可审计。

**个人持仓**：份额、成本、现价/市值、浮盈、权重、动作、预测、S/R、更新时间；CSV/XLSX/OCR导入共用候选→映射→复核→确认。识别基金代码、名称、成本、份额；模糊代码/小数点/重复标的待人工处理。禁止确认前写入；导入/编辑不篡改共享信号。点击进入同一ETF详情。

**因子研究**：目录、有效样本、方向、状态、相关性矩阵、分年/OOS、组合风险；另设风格方法论候选。个人成本/盈亏不是市场预测因子；见治理文档。

## 6. 颜色与组件建议

| Token/用途 | 建议值 | 说明 |
|---|---|---|
| sidebar / app / panel | `#09090B` / `#111113` / `#18181B` | 接近截图的层级，非采样复制 |
| border | `#2A2A2E` | 低对比边框而非大片彩色背景 |
| text / muted | `#F4F4F5` / `#A1A1AA` | 小号灰字仍需对比度验收 |
| accent / focus | `#22D3EE` | 选中竖条、焦点、主要交互；不代表涨跌 |
| rise / fall | `#F87171` / `#4ADE80` | 中国行情涨红跌绿，同时带正负号 |
| warning / forecast | `#FBBF24` / `#A78BFA` | 数据警告；未来研究情景 |

危险/失败与行情下跌分离，不能统称“风险=绿色”。动作保留文字；颜色不是操作指令，也不是概率。侧栏建议232px，折叠64px，顶栏60px；窄屏侧栏变抽屉，保留搜索。卡片圆角6–8px、轻边框、少阴影；数字等宽，中文正文清晰。不从截图固定比例推导所有屏幕布局。

## 7. 动效、可访问性与验收

建议选中/悬停120–180ms，侧栏折叠180–220ms；遵守 `prefers-reduced-motion`，禁用闪烁涨跌/循环大动画。加载用骨架/明确进度，不能用动效遮盖错误。图表数值另有可读表格；不能仅以红绿区分。

验收桌面1440、平板1024、窄屏390：焦点可见、ARIA当前页、Tab顺序、搜索动作不冲突、表格横向滚动不撑破整页、刷新/前进/后退保存选择、退出清私有缓存并撤销会话、用户A不能读B持仓/研究/密钥。

## 8. 保留的真实性合同

指标状态≠历史条件频率≠OOS校准概率。没有样本外证据时不得显示“MACD上涨概率80%”之类虚构数值。当前KDJ状态边界以 `config/strategy.json` 与统一状态函数为准；本轮不调阈值。预测仍使用已结算日线快照，14:30临时观测不混入历史收盘邻居；概率校准资格不由AI判定。

图表库不是本轮实施项。未来以缩放/图层/性能/许可证/CSP验收判断保留Canvas还是自托管专业库，不把既有实现自动视为永远不能替换。
