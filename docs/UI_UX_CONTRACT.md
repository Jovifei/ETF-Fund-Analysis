# 工作站 UI/UX 合同（rc.2）

本合同描述本源码包新UI，不声称远端main/生产已切换。入口开关 `WORKSPACE_UI_ENABLED=true`；旧界面原文见 [归档](archive/main-3c7bdc7/docs/UI_UX_CONTRACT.md)。

采用原创Kairo式暗色侧栏、顶部全局搜索、底部账户区。不是Kairo源码/素材复制。主背景深灰黑，青色为导航/操作强调，红涨绿跌，紫色为预测；状态除颜色外有文字，不把绿色运行状态当上涨。
桌面侧栏展开/窄栏/隐藏；移动端抽屉、Escape关闭和焦点管理；账户区设置、个人中心、退出。无认证演示不能假称已登录，退出不可用且明示演示。

| 入口 | 路径与职责 |
|---|---|
| 市场总览 | `/`：跟踪ETF、全市场指数/宽度、板块范围分开；只读快照 |
| 板块 / 14:30 | `/boards`、`/decision/1430` 共用总览壳；保持服务端语义 |
| ETF分析 | `/analysis` 标的目录，`/etf/{code}` 全局唯一详情 |
| 自选与持仓 | `/watchlist`、`/holdings`；确认前不写持仓，支持撤销冲突检测 |
| AI与档案 | `/ai`、`/review`、`/history` 共用研究组件；`/research/news` 新闻证据 |
| 因子 / 账户 | `/factors`、`/settings`、`/profile` |

旧 `/research` → `/history`，`/system` → `/settings`；`/legacy#holdings/news/system/signals` 兼容；旧14:30仍归总览二级。
普通URL直接刷新有精确后端路由；不存在API或静态资源不能被SPA回退成200。不得同时加载旧app.js与Vue共同操作DOM。

搜索仅ETF/LOF；四动作分别是打开图表、加自选、预填持仓、打开AI草稿。打开草稿不调用模型。
搜索只查已同步目录，不假称目录完整；后台onboard与持续研究池上限独立。
所有私有数据只驻内存/受认证后端，登录切换失效旧请求；偏好不是认证信息，可以单独保存。

图表由KLineCharts渲染已有服务端序列：滚轮、拖拽、60/100/250范围、十字线、复位；MA5/10/20/30/60、VOL、MACD/KDJ/RSI；当前支撑压力bands与下方价格图例，金色个人成本线。
S/R不是历史点位回放，预测不是实K。成本与价格基准不兼容就不叠加；分钟指标未合格不冒用日线。
未校准预测显示历史相似样本上涨频率/占比，不生成技术指标“准确概率”。缺失显示缺失，不填0或静态行情。

界面验收截图在 `evidence/screenshots/`，全部Mock。生产真实数据、真实账户登录与HTTP浏览器测试另验；[当前验收](TEST_REPORT_20260906.md)。
