# v1.0.4 用户操作：先有数据，再看图，再研究

## 市场总览和板块

总览仍为唯一主页。上方指数卡片打开指数蜡烛图；行业/概念下面“查找相关ETF”进入同一个基金目录。元器件可关联电子/半导体/芯片，非金属关联建材等，页面显示命中依据。关联是文字与跟踪指数语义，不等于持仓成分穿透；有的板块确实没有专门ETF。

点击“同步市场目录与板块”后看任务步骤和工作器心跳。排队并不表示抓取完成，失败不会变成绿灯。只有36只通常仅有种子/有限同步记录，不能作为市场发行总数；代码会继续尝试独立ETF/LOF分类端点，而实际网络仍需可达。

“已知市场市值”与净资产AUM不同，未知市值不会被推测。可以按成交额/市值排序，再勾选最多30只准备历史。目录应尽量完整，但只对用户关注、持仓和重点研究池做持续计算。搜索可包含货币、债券、商品、跨境等场内产品，不按基金名字是否含ETF一词决定身份。支付宝上的联接/场外基金不可偷换成同主题ETF。

## 图表周期与辅助线

顶部“日K、周K、月K”决定每根蜡烛覆盖的时间；60/100/250只决定可见根数。周/月取首开、最高、最低、末收，只有全部量值已知才合计量。未结束的周/月标partial，缺失交易日不虚构。小时数据不存在就显示不可用，并始终保留返回日K入口。

右侧勾选MA、价格结构、MACD确认、KDJ确认、RSI确认、布林、ATR、Fibonacci、缠论近似，也可开全部/关闭。最近支撑/压力卡片显示价格及距离；这些是研究参考，不保证价格在这些位置反转。MACD零轴、KDJ20/90是指标阈值而非基金价格。MACD/KDJ分组价位指在相应指标状态支持下识别的价格拐点。

缠论近似来自既有算法中的区间重叠，不等于完整包含处理、笔、段、分型、中枢、背驰系统；不要据此直接执行交易。图表支持缩放、平移和全屏，Esc退出全屏。

“技术指标快照”显示当期值、上一根/上一快照、变化与解释，例如KDJ52只属于中间区，仍需看K/D方向和趋势，不能单值判断买卖。

## 决策快照和预测

原版五档决策模板仍嵌在总览，不是另一个站点。点“今日涨幅”可在各组内升降序；空值始终在末尾。小星标只收藏不打开详情。保留当期/前次指标对比，移除和今日涨幅重复的“较昨日”红线列；前次指标不一定就是自然昨天，显示其日期。

主研究期限显示未来1、5、20个交易日（约明日/一周/一月），图表的周/月K与预测期限是两件事。共同缓存由明确任务重算，ETF详情和总览使用同一份，不额外调用AI。20日至少需要250根已结束日K；没有样本就显示不足，不放大一天预测冒充一月。3/10日旧合同保留在高级选项。全部相似样本频率均未校准，不能等同保证或真实概率。

## AI、复盘与档案

进入“AI研究”：先在“模型API连接”保存地址/Key/模型并设为本人默认；也可按“本地Codex”页内步骤配对设备。保存和浏览不计费。建立证据任务后选择共用配置，勾选费用确认，再开始研究。任务仍需API+worker运行；结果作为待审核候选，核对来源、时间与缺口后批准。

“导入外部原生研究产物”放在高级区域：只有已经在Vibe等工具生成报告时才用。不需要先准备文件才能用网站自己的API分析。固定证据是为了知道AI看到了什么，报告审核是为了防止生成内容直接替换指标/动作，MCP不是必需。

每日复盘可自己写，也可用同一默认AI配置生成草稿；后续结果用于提出可验证假设，不能直接自动训练/上线参数。因子研究先勾选1–12个因子再点击运行诊断，查看覆盖率、IC、相关性等，而不是勾选后直接得到未来收益。研究档案只读回看已经保存的任务/报告，不会扫描本地磁盘。

## 新闻、账户

新闻“发布于”和“抓取于”分别代表事件来源时间和本站读取时间。9月7日消息在9月9日仍可能是最新成功抓取的历史记录，页面标年龄；点击刷新建立任务，源接口没新消息也不能改日期。时间筛选只作用于当前已加载记录，不宣称全网覆盖。

个人中心中管理员可创建成员、调整角色与普通/Plus分类、停用/恢复或可恢复移除。移除不会悄悄删持仓/审计。最后管理员和自己的关键操作受到保护。会员不是管理员角色；权益策略默认不拦截已有功能，只有管理员明确启用后三项受控研究能力按服务器校验。付费订阅收费流程不在本版。
