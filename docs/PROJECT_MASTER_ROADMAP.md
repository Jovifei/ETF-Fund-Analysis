# 产品路线：网页和App的本地研究工作台

目标：真实数据留本机，定时计算后只推有界展示结果；用户在网页与未来App理解市场、图表、持仓与风险，由人决策，不自动交易。

## 当前优先顺序

1. 修复并验收网站读取超时，证明生成→接收→总览/详情/K线同代消费。
2. 修复收盘日线缺口，验证尾盘时效与跨日恢复；过期/缺失/失败清楚展示。
3. 固定发布跨两个真实交易日观察slot、接收、页面及云端研究表/缓存资源；证据不全保持未通过。
4. 正常手机网页验收后，再设计App形态；不把代码合入、上传成功或网页可访问当成独立App交付。

## 能力地图

| 能力 | 后续验收 |
| --- | --- |
| 数据与运行 | F盘持久化、固定任务、漏跑恢复、同包同步；实际时效/重启/断线证据 |
| 网页与App | Vue总览/详情/窄屏先稳定；未来App复用认证与研究API |
| 图表和解释 | 日/周/月、价格口径、指标/支撑压力/Chan；确认、候选与重绘边界清楚 |
| 预测研究 | 当前1/3/7/20/60；独立样本、walk-forward、PIT/OOS、校准和基准比较后评估可靠性 |
| 上下文与消息 | 来源、时间、部分/沿用/不可用明确；AI只解释证据 |
| 私有持仓 | 用户隔离、人工确认和风险研究，不自动下单 |
| 稳定运营 | 有界内存/磁盘、自然任务、备份/恢复/回滚、长期soak |
