# K线企稳分析看板 · Reference v4 页面契约

本文件把公司参考页/用户提供截图的主决策视图固化为工程契约，防止后续 Agent 再把页面改成工程后台式多列诊断表或独立评分卡。

## 1. 当前结论的唯一来源

当前 ETF 的五档结论只有一套：

- 可加仓
- 可入场
- 可试探
- 观望
- 减仓

主决策看板使用 `DecisionBoardSnapshot.rows[].grade`，该字段来自 `SignalGradeService` 的 MA / MACD / KDJ / 量能五档分级。

信号中心不是第二套“当前结论”。信号中心当前前排在有 DecisionBoardSnapshot 时，`state` 必须复用同一 `grade`；`SignalSnapshot.score × coefficient` 仅用于机会/风险前排的排序，`take_profit` 仅用于过热提示。历史曲线继续使用历史 SignalSnapshot，因此其历史统计与当前五档分组并非同一个时间序列口径，UI 必须明确说明。

## 3. 色彩语义

行情价格采用中国市场习惯：红涨、绿跌。

方向类状态采用参考页语义：

- 较昨日 ↑：绿色
- 较昨日 ↓：红色
- 均线 ↑：绿色
- 均线 ↓：红色
- 板块上涨家数：绿色
- 板块下跌家数：红色

五档：

- 可加仓：绿色
- 可入场：蓝色
- 可试探：金色
- 观望：橙色
- 减仓：红色

## 4. KDJ / RSI / 量能 / MACD 展示语义

KDJ：

- J > 100：超买 / 钝化，短期回调风险高
- 90 <= J <= 100：偏高，谨慎追高
- 20 <= J < 90 且未死叉：健康
- J < 20：低位 / 超卖
- K 下穿 D：死叉，优先风险展示

RSI：

- RSI >= 70：超买
- 50~70：正常偏强
- 30~50：偏弱
- RSI < 30：超卖

量能：

- 放量 >= 1.15
- 平量 0.90~1.15
- 缩量 < 0.90

MACD 的页面词汇：

- 强势金叉：gold 且 DIF > 0
- 弱势金叉：gold 且 DIF < 0
- 多头延续：bull_cont 且 DIF > 0
- 修复延续：bull_cont 且 DIF < 0
- 将叉：approach_gold
- 将死叉：approach_death
- 死叉：death / 持续空头区域

这些是显示词汇映射，不改变后端 `kind` 及五档分级算法。

## 5. 九转边界

当前工程只实现 TD9 Setup，不冒充 TD13 Countdown。

当 TD9 序列达到 9：

- sell setup：显示“TD9 下跌变盘”
- buy setup：显示“TD9 上涨变盘”

不足 9 时只显示当前计数和序列方向。

## 6. 预测与 conf

默认主表展示明日预测；可切换 3/5/10 日。

主表显示：

- expected_return
- conf
- conf 解释

参考解释：

- conf >= 60：样本一致度较高
- 40~60：弱信号
- < 40：忽略

但只要 `calibration_status != calibrated`，页面必须继续标记为研究结果；conf 不得解释为真实预测准确率。

## 7. 页面信息结构

主页面顺序：

1. 顶部系统导航
2. 看板标题 / 标的数量 / 数据源 / 时间
3. 五档统计
4. 全部标的涨跌条
5. 指标图例
6. 控件（五档/综合排名、预测周期、筛选）
7. 盘中总结
8. 五档分组表格
9. 盘中核心变化（对比昨日）
10. 明日/3/5/10 日预测摘要
11. 数据来源 / 指标公式 / 研究边界

点击 ETF 行继续打开详情：历史 K 线、未来研究情景、支撑压力、缠论近似、六项综合评分、多期限预测。
