# ETF 信号分级研究视图（signal-grade-v0.1.0）

日期：2026-08-30  
性质：只读研究展示层。不改写生产信号引擎 `signal-v0.7.0-research`，不写 Holding，不连接券商。

## 边界

- 指标由确定性 Python 从已落库 `IndicatorSnapshot` / `QuoteSnapshot` / `ForecastSnapshot` 派生。
- LLM 不计算 MACD、KDJ、RSI、均线、量能、仓位或预测数字。
- 预测格必须标注 `FORECAST · 非实际结果`；`calibration_status` 保持上游值（默认 `not_calibrated`）。
- Mock / 退化 / 时间戳未验证时 `actionable=false`；分级标签仍可展示但带研究提示。
- 不爬同花顺行业指数（如 `884286`）；只展示场内 ETF/LOF。
- 全市场涨跌家数无合格数据源时显示「未验证 / 不可用」，不编造。

## 页签

新增第 6 个页签「ETF信号分级」，不替换「信号中心」。

## 五档（互斥，先看空后看多）

1. 数据不足 → `数据异常`
2. KDJ 死叉或 MACD 死叉/将死叉 → `减仓`
3. J≥90 或放量滞涨 → `观望`
4. J&lt;90 且上涨放量且均线多头排列 → `可加仓`
5. J&lt;90 且结构向好（多头或 MACD 修复/金叉）且非超买 → `可入场`
6. J&lt;90 → `可试探`
7. 其余 → `观望`

文案均为研究提示，非操作指令。
