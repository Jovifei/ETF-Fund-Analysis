# 使用说明（本地研究看板）

本系统是私有中国 ETF/LOF 研究台：可以看状态和仓位变化提示，**不连接券商、不下单**。预测在人工校准前一律视为未校准研究输出。

## 本地 Docker

1. 按 `QUICKSTART.md` 准备 `.env`（从 `deploy/.env.local.docker.example` 复制，设置数据库密码）。
2. `docker compose up -d db api`（资格完成前不要开 scheduler）。
3. 打开 `http://127.0.0.1:8080/`。
4. 账户登录：迁移后在服务器本地运行 `fund-decision auth-bootstrap-admin` 创建首个管理员。浏览器输入用户名和原始密码；密码只以 Argon2id 哈希保存在数据库，会话是 HttpOnly cookie，不会写入 localStorage。不要把密码发到聊天或截图。

生产环境不接受旧 Bearer 凭据或 `AUTH_USERNAME`、`AUTH_EMAIL`、`AUTH_PASSWORD_HASH`、`AUTH_SESSION_SECRET`。当前版本不发送 SMTP 邮件，也没有 OTP。

## 行情开关（先能用，再可选更完整）

打开 **系统** 页右侧 **行情数据源**：

1. **先能用 · 免费公开行情**：AKShare 调东方财富公开 ETF/LOF 日线，不必填 Token。
2. **更真实更完整**：勾选后粘贴 Tushare Token，点「保存数据源」，再用「测试是否连通」。Token 只写入本机，页面和接口都不会回显。

「测试是否连通」在免费档先探测东财公开接口，若已配置 Tushare Token 再探测第二候选；完整档探测 Tushare。演示/Mock 环境会明确说未出网，不会假装成功。选了完整档但还没 Token 时，拉数仍走免费源。

Docker 启动默认仍看 `.env` 的 `MARKET_PROVIDER`（前期用 `akshare`）。登录后顶栏会显示实际 `provider`。拉数：打开 **系统** → **完整流水线**（或「更新日线」再「重算指标」）。分数由 Python 按公式算，不是聊天模型打的。

### 隔离演示

如果只是想验证页面和分级，不要把正式行情切到 Mock。系统页选择「演示数据 · 隔离 Mock」并点击「加载演示数据」：

- 使用进程内 SQLite 和 420+ 天合成日线，不访问外网、不写正式数据库、持仓、ProviderAudit 或报告目录。
- 顶栏和卡片会显示 `DEMO` / `Mock`；所有结果均为研究演示，`actionable=false`。
- 演示期间正式任务、设置、持仓和 OCR 变更会被禁用；退出后恢复正式看板，API 重启后演示数据消失。

正式「更新日线」默认回看 120 个自然日，约覆盖 80 个交易日；30 个自然日通常不足 30 根交易日，
因此页面不会再把空库误报为「数据异常」。状态含义为：未运行是「待初始化」、日线不足是「历史数据不足」、
Provider 请求失败是「数据源不可用」、已有足够历史但指标失败才是「数据异常」。

### FTShare 只读备用源

FTShare 不是必填 Token，也不是演示数据源。应用只重实现固定的 ETF 列表、日线和现价 HTTP 契约，
不执行第三方 Skill，不接受前端自定义 URL/工具名，默认 `FTSHARE_ENABLED=false`、
`FTSHARE_QUALIFICATION=unverified`。运行有界资格探测并人工确认服务许可、额度、缓存和再分发条款后，
才可将两项配置成 `true` / `qualified`；否则应用跳过 FTShare，失败不会静默回退 Mock。操作和当前证据见
[`docs/FTSHARE_PROVIDER.md`](FTSHARE_PROVIDER.md)。

### Tushare 要不要付钱

Tushare 不是本系统的订阅费，而是**积分门槛**：调用一般不扣积分，积分不够则部分接口调不了。以官网为准（会变）：<https://tushare.pro/document/1?doc_id=290>。个人档大致是：约 120 积分免费（主要非复权日线、次数低）；约 200/500/1000/1500 元/年对应更高积分与频次；分钟线、盘中实时、新闻等另计（例如实时日线约 200 元/月）。机构约 10 倍，官方称购买后不退款。

前期不必购买。先用免费档把页面和打分跑通。需要更稳的日线和基金基础信息时，再在系统页填 Token 并改到完整档。

## 页签含义

| 页签 | 作用 |
|---|---|
| 决策看板 | **行业板块 / 概念板块**卡片（主题 ETF 代理得分与 K 线）。市场环境六卡只是宽基观察，不是进入行业的依据 |
| 信号中心 | 机会 / 风险 / 止盈 研究前排与曲线；系数只改本页 |
| ETF信号分级 | 单基五档宽表（可加仓/可入场/可试探/观望/减仓） |
| 持仓 | 手工或 OCR 导入后的账户记录；确认前不写库 |
| 新闻事件 | 证据向新闻与主题映射 |
| 系统 | 任务、Provider 审计、设置。无日线时在此运行「完整流水线」 |

板块名称对齐东方财富常见叫法，不爬东财板块指数页。`akshare` 只拉场内 ETF 日线。无代理 ETF 的板块显示「未验证」。

## 当前卡点与下一步

前期用系统页「先能用」或 `.env` 的 `MARKET_PROVIDER=akshare` 测行业卡片和打分即可；只想体验完整页面时使用隔离演示。需要更完整行情时再在系统页填 Token 并改到完整档。FTShare 仍需独立资格确认；ECS/HTTPS 与影子运行仍待目标环境。

分析模型的 Tushare Token 明文落库问题仍是单独的生产安全整改项，本次 FTShare/演示改造没有处理，
不能把当前本地配置或 Mock 资格当成生产安全证明。
