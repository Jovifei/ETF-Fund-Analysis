## 可执行的只读对账

仓库外设置DATABASE_URL指向已备份副本，安装同版环境后运行：

```powershell
.\.venv\Scripts\python.exe scripts/audit_research_inputs.py --codes 510300.SH 512480.SH 588200.SH --output E:\ETF_Private\audit-20260913.json --fail-on-blockers
```

报告逐标的列出目标/最早/最新日期、来源版本/复权基准、量额缺失数、价格断点、指标版本/schema/config/date缺口及全段输入hash。只读SQL连接，不创建表、调用Provider、加载模型或授予资格；输出不能覆盖旧文件。默认退出0只代表报告成功写出。增加 --fail-on-blockers 时，历史或指标任一缺口退出3，工具/IO错误退出2；两类都没有检测到缺口才退出0，但仍不授予资格。汇总分别显示history_blocked、indicator_blocked和不重复的blocked，不能漏掉仅指标版本/日期缺口。超过20000根明确标记未审完整历史，不能静默当全量。
