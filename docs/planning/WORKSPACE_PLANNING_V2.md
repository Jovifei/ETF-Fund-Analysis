## 2. 两份方案的合并裁定

保留 FastAPI/PostgreSQL/Alembic/Provider Adapter/HttpOnly Cookie+CSRF；采用 Vue 3、TypeScript、Vite、Vue Router、Pinia 与统一 fetch client。同源构建部署，不添加常驻 Node BFF。
Kairo 截图提供原创布局参考，不复制品牌/源码/账户截图。深色中性色、青色交互强调、红涨绿跌、紫色预测；风险标识不冒充行情方向。180—250ms 是本项目动效预算，支持 reduced-motion，不是原站测量。
KLineCharts 9.8.12 经 ChartAdapter 渲染服务端数据，不使用内置指标作为第二计算来源；迁移失败可关闭开关回旧壳。
Vibe-Research 是首个独立试点；TradingAgents 仅角色/反证参考；QuantDinger 后端 Apache 与其独立前端 source-available 许可分开，不复制前端；tick 仅交互参考；KHQuant skill 不是行情授权或内嵌回测引擎。
DSHQuant 的 `harness/home/skills` 空模板与 `assets/skills` 研究材料分开核验，不能统称全部可用或全部空白。因子数量是目录数量，不是验证结论。抖音视频未读取，不作为实现证据。

## 4. 页面与迁移合同

日常：总览、ETF分析、我的自选、我的持仓。研究：AI研究、研究档案（每日复盘/新闻/历史）、因子研究。
底部：数据/AI状态摘要、设置、个人中心、登录退出。无能力时显示明确空态和下一步，不制造完成状态。
所有 ETF 点击进入 `/etf/{ts_code}`；14:30 是总览二级模式；板块保持可达。
每个页面通过测试后才开启；旧壳与 Vue 不共同操作 DOM。API/auth/health/assets 优先于页面，不能 catch-all 返回200。
公共行情缓存不含持仓；身份变更取消请求并清空私有内存；搜索/切换标的防迟到响应覆盖。
目录与持续研究池分离。只读 GET 不触发 provider/模型/回测；异步任务由既有进程/独立 worker 执行，查询提供状态。

## 5. 图表和量化语义

图表序列由现有 Python core 公式生成，初始化/预热/缺值不改。核对 MACD hist 倍数、KDJ 初值、RSI 与快照精度。截断历史标注，版本或复权混杂不声称对齐。
成本、S/R与价格需同币种/复权口径；无法转换时禁叠而非猜。当前 S/R 不伪装历史当时可知，forecast 不加入真实 OHLC 或技术指标。成交密集区如由日bar估算，明确估算标签。
分钟数据不足时 unavailable；盘中日bar明确 partial；30/60m展示不替代5/15m的14:30 PIT验证。
唯一动作仍为现有 canonical current action。多空指标数/研究评分/历史上涨频率/校准概率/LLM置信说明分开。horizon固定1/3/5/10；Mock永远actionable=false。

## 6. 研究与安全合同

模式A：固定、净化证据→有预算单次研究→候选。模式B后续仅允许受控Provider/MCP采集，不允许任意Shell/数据库/URL/插件。
独立CODEX_HOME只隔离配置认证，不冒称OS沙箱。个人官方登录不得上传认证文件或共享给网站用户；自动化适用性、额度和登录恢复单独验证，不静默切付费API。
模型Key/数据Token/网页会话/设备上传凭据分开。Linux0600是权限不是加密。外部项目无生产DB/SSH/券商凭据。
网站是全局任务状态权威；Bridge适配任务与产物；Vibe只维护内部阶段。先手动包导入，后主动HTTPS回传，最后定时。
协议绑定schema、owner（由认证决定）、job/attempt、输入快照和hash、版本、证据可见时间、引用、缺失和用量。hash不等于身份或事实真实性。
执行/数据资格/人工审核三种状态分离；设备不能发布或改动作。需防重放、跨用户、半文件、取消后迟到、恶意Markdown和路径穿越。
日复盘依赖按任务定义，可选模块失败生成明确降级稿，关键数据不足阻断相应判断；不要求所有可选预测成功。单worker/有界队列/每日预算，离线显示最后成功日期。

## 7. 分阶段提交与门禁

P0：本合同和来源/需求对账；P1A：Vue壳+ChartAdapter+测试；P1B：固定上游隔离试点（演示/真实独立状态）；P2：无AI完整路径；P3：研究包/审核/回传/调度；P4：小因子诊断/个人风险/风格模板/运营。
P1A与P1B可并行。代码测试通过不代表真实模型/数据/分钟回测/长期Shadow资格通过。
每阶段应记录实现文件、测试命令及结果、剩余限制、回滚。新增Vitest/typecheck/build/Playwright不删除原pytest/JS/secret/Alembic/ShellCheck/Compose/Docker门禁。
Q研究资格线并行保留：真实5/15m PIT→执行价/费用/滑点/规则→事件回测→purged OOS校准→Shadow→人工批准。不得用CI或演示自动升级。
本轮不操作生产数据。未来生产上线必须备份、迁移、health/provider audit/smoke和回滚；个人模型登录与真实数据资格需要实际环境证据。
