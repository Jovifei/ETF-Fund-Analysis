# 因子、持仓分析与交易风格 Skill 治理

2026-09-06，规划稿；未安装任何上游Skill，未改变生产因子/预测配置。

## 1. “持仓因子”必须拆开

| 类别 | 回答什么 | 实现建议/限制 |
|---|---|---|
| 个人持仓状态 | 我承担多少风险，成本离防守区多远 | 权重、盈亏、回撤、成本距离、集中度；仅user-scoped，不当作市场上涨原因 |
| ETF穿透持仓 | 多只ETF是否买了同一批资产 | 官方已披露成分/持仓权重、重叠度、行业暴露；披露滞后/覆盖率必须显示 |
| 机构/股东持仓变化 | 外部投资者持仓是否变化 | 个股第二阶段；需公告可见时间，不能用报告期末日期提前知道公告 |
| 决策后因子归因 | 哪类研究判断后来兑现 | 决策时点因子值→后续收益/风险；必须按每次决策而非只按代码合并 |

同一指数不同基金、同主题不同ETF先识别重叠，不能把高度相关暴露当作分散。相关性不等于成分重叠；穿透数据不全时同时显示权重覆盖率和披露日期，不补成100%。债券/商品/跨境ETF不硬套A股公司财务公式。

## 2. 对“120多因子”的审阅结论

DSHQuant README宣称123+；本轮未验证全量可运行数、独立公式数或ETF效果。其 `factors/factor_engine.py` 内 `rps_120` 与 `mom_120` 都取120日涨幅，是一个实际的同义/高度重复例子，不能按两个名字算两份独立证据。其ETF映射模块已有策略收益—ETF收益相关、滚动稳定性、流动性与去冗余思路，值得迁移方法而非照搬权重。

tick-stock-panel因子平台文档较README更新，记录目录扩到77；这依然是上游自报范围，不是我们的资格证明。数据接口数量、指标列数量、Skill数量和有效独立因子数量必须分开计数。

## 3. 首批ETF因子/风险研究建议

建议8–12项/族小池起步：趋势位置、短中期动量/反转、波动/下行波动、量能与流动性、市场广度/主题强弱、支撑压力距离、溢折价（有可靠源才启用）、跨ETF收益相关性、可得持仓重叠、新闻事件热度。先复用现有确定性计算；无源的设unavailable。个人成本、份额和持仓盈亏是风险上下文，另表存放。

每个FactorSpec记录：ID、公式版本、方向、适用asset_type、窗口、字段单位/复权、源与available_at、更新频率、缺失处理、样本期、许可证、状态。状态建议candidate → evaluating → research_approved → monitoring → retired；生产准入另行人工批准，不能用上游active状态直通生产。

## 4. 因子页与验证

侧栏“因子研究”：目录、相关性、单因子检验、组合风险、风格候选。展示有效样本N、期间、频率、收益期限、状态，而不是只给一个漂亮热力图。

相关性区分：同日ETF横截面因子秩相关、同一标的时序特征相关、ETF收益相关。三种矩阵不能混用。先去同义公式，再做相关性聚类；阈值预先登记，不为凑120个临时放松。

验证按ETF类别和市场状态做IC/RankIC、分层收益、换手、成本、分年稳定性、purged walk-forward、独立Holdout与多重检验控制。宽基/行业/跨境/商品/债券样本不任意混算。小池横截面统计不足要明确置信范围，不把偶然高IC写成稳定Alpha。1/3/5/10为当前预测合同；增加20D另开版本化研究。

持仓归因需记录decision_id、当时因子版本/值、入场与退出可见信息、执行假设，不能因为同代码的最新收益覆盖多次历史交易。上游 `risk/factor_attribution.py` 的统计结构可借鉴，但不足以直接证明因果贡献。

## 5. 交易风格Skill：有，但不是“复制交易员”

已读 DSHQuant 的 `assets/skills/niu-san-distillation/SKILL.md` 和 `niu-san-zhangmengzhu/SKILL.md`；目录还列出林园、陈小群、赵老哥、炒股养家、冯柳等。用户口述“张萌”可能指章盟主，因未能观看视频，**不作确定认定**。

这些通常是把公开材料整理成规则、反例和研究流程，不是对真实交易员模型权重的蒸馏，也不意味着本人授权、背书或收益复现。不得把无法核实的战绩/席位传闻用于营销。

额外发现 `tradermonty/claude-trading-skills`：Druckenmiller式方法综合、交易复盘、风险复核适合低频方法论。其 `portfolio-manager` 默认依赖Alpaca，必须替换为我们的只读持仓接口；不接券商、不全局安装整套Skill。

Skill准入：来源+许可证+精确revision → 人工审阅提示/脚本/依赖/网络权限 → 去自动交易/任意Shell/自动升级 → ETF适用性改写 → 固定测试集 → 研究候选 → 人工发布。先做“趋势跟随”“防守型配置”“逆向观察”等清晰模板，短线打板/龙虎榜风格留给个股研究。每个风格只输出解释与待检验假设，不改指标或current action。

## 6. 强制边界

AI可提因子假设；确定性程序算值；独立研究环境做评估；人工批准决定是否升级。禁止把自进化循环、自动挖掘、参数热更新复制到生产。任何被淘汰因子保留失败原因和版本，防止下一位AI反复重做同一个已证伪实验。
