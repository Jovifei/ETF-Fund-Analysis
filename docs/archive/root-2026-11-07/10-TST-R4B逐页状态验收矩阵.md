# R4B 逐页与状态验收矩阵（2026-09-27）

## 环境

使用隔离 Mock 服务、临时 SQLite、虚构账户。普通、认证、响应式 Playwright 顺序运行且 `retries=0`；服务绑定 `127.0.0.1`。这证明本地页面行为，不证明生产账户、真实行情或手机 Safari。

## 图表专门验收

- K 线蜡烛与服务端指标保持可见；箱体覆盖只出现在 origin/confirmation 有界区间，不铺满历史画布。
- 已确认与候选分段绘制；候选、盘中临时尝试和结算状态有独立文案。临时输入不写入结构快照。
- 默认箱体及两级支撑/压力；MA、BOLL、ATR 和派生参考可按图层开启；点击图层不会重建蜡烛画布或调用 Provider/模型。
- 原始/研究价格基准校验失败时隐藏叠加；周、月和分钟周期不借用日线箱体。
- 视口检查覆盖 320、390、430、768、1024、1440、1920、3840 CSS px；另有 390×600 短屏弹层、触摸、DPR2、横竖屏与 CSS zoom 回归。

## 覆盖边界

并非每个页面的每个 API 都注入了所有 HTTP 状态；矩阵标明本批新加的真实页面状态注入与沿用的既有流程。未测生产认证会话、真实 Provider、新数据资格、PostgreSQL（缺 `TEST_POSTGRES_URL`）和真机 Safari，均不标成 PASS。
