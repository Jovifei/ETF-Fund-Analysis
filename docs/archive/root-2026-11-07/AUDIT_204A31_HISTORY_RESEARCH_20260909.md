基线：`204a31cbc0214a6e80389224c238bc897b2279af`，来自 `codex/parallel-v102-gapfix-20260908`。源归档 Git tree 已核对为 `68e56857d4f8885243ae3aa9a7fb12a3c09f39ef`。本轮在独立分支修复，不覆盖原分支、main、用户配置或数据库。

## 已确认的实现问题

1. `workspace/worker.py` 的 `bar_failed` 在任意一只基金日线 partial 后跳过整批指标、预测、信号与决策快照。`providers/data_contract.py` 还有全池历史门禁。门禁不能删除，但历史展示不应被一起阻断。
2. 目录搜索可返回未跟踪基金，目录同步不下载历史。详情没有直接补历史按钮；因此“能搜到”不代表“已经有 K 线”。
3. `read_model.instrument_detail` 的数值卡片仅取持久指标快照；无快照时，即使有合法历史价格也为空。旧单位历史的图表分支还同时隐藏所有价格类指标。
4. 原版模板读取唯一决策快照；没有快照时没有解释性历史行。需要保留原模板与权威动作，增加明确标识的历史展示投影，不能生成第二套买卖评级。
5. `204a31` 的市场上下文 history 只有 observed_value；SVG 是点位观察折线，不是真实 OHLC K 线。需增加指数 OHLC 存储与受控取数，不伪造开高低收或今日日期。
6. 收藏按钮仅在详情/全局搜索，目录和原表中不可见。应复用已有用户隔离自选接口并标明状态。
7. 图片导入已有候选/确认流程，但本地 live runner 强制 OCR_MODE=disabled；需提供显式配置和能力说明，不能把引擎不可用伪装成识别成功。
8. AI 研究现有证据导出/Bridge/候选审核，但 API 密钥通路明确未实现；复盘缺少直接人工编写与反馈入口，因子页只有诊断，不能选择因子进行隔离实验。

## 修复验收范围

- 已入库历史优先显示；价格指标与量能/实时/预测资格分离；GET 不访问行情商、不修改快照。
- 按标的补齐历史、重复任务去重、失败不清空旧数据；保留当前唯一动作与正式 1/3/5/10 期限。
- 上证指数、沪深300、中证全指真实 OHLC 图和最新观测点位/日期；无今日数据明确使用最后交易日，不填假现价。
- 复用原版 ETF 快照 HTML/CSS，增加收藏与历史状态，不换模板或复制主页。
- 人工复盘优先、AI 显式调用、因子实验隔离；20交易日仅月度研究实验，不自动扩展生产模型。
- 本地归档/上传采用版本化公开行情包，不同步数据库文件、不上传账户或持仓、不放开原研究设备的写行情权限。
- 用户私有配置/真实模型/真实行情可用性分别验证；离线测试与当次网络探测不相互冒充。
