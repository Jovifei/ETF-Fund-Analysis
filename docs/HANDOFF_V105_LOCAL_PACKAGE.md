## 接收顺序

1. 下载后在全新目录解压。先执行 `python verify_bundle.py`，应全部匹配。`FILE_MANIFEST.json` 是本包唯一完整性清单，不使用源码里保留的历史 DELIVERY_MANIFEST/PACKAGE_MANIFEST。
2. 把 `01_CODEX_PROMPT.md` 交给本地 Codex。推荐在独立 clone/worktree 切到固定基线后应用 `patches/`；不能覆盖旧脏工作树。
3. 检查 `02_CHANGELOG_AND_GAPS.md`，区分已包含修复与待完成的 UI、线上、Windows、真实数据验收。
4. 执行全量后端、前端、独立 PostgreSQL、真实 HTTP Playwright；必要修复另行提交。先备份用户库，在副本验证，测试不得连接用户库。
5. 本地应用、worker 连接同一持久库，并重建 Vue。先手动补采，核对源时间、抓取时间、计数和单位。**`BALANCED_REFRESH_ENABLED` 默认 false；没有单一 scheduler 审核和一次手动成功，不打开定时。**

# 本地验收矩阵与数据逐字段核对

## 隔离与身份

- 原工作树只读盘点 path/remote/HEAD/脏文件名；新clone/worktree；用户配置、持仓、数据库及模型登录留在仓库外。
- 包身份：固定基线46c713d + SOURCE_CHANGESET.json + patches目录中补丁SHA256。接收后 HEAD 仍可能是基线、diff非空；本地提交后才记录新代码 SHA。
- Git apply 必须 --check；新远端存在并发改动时做三方审阅，不镜像覆盖、不强推。
- 数据备份有校验并在副本演练；不将测试迁移/清库/种子指向用户或生产库。

## 每类数据保存一行脱敏证据

字段：界面名｜Provider具体操作｜参数范围｜耗时｜返回数｜入库数｜去重数｜最后源日期/时间及其时区｜最后抓取时间及其时区｜最后计算时间｜失败分类｜资格｜API路径｜页面显示。

1. 目录：ETF/LOF数量与统计范围，覆盖宽基/行业/货币/债券/跨境；目录不是计算池。煤炭开采加工、军工装备/设备、元件查找相关ETF有结果和依据，非金属不误匹配有色；搜索不写库或拉行情。
2. 现价：采集时间不得替代交易所/数据商时间；验证timestamp_verified/is_realtime/degraded_reason；周末/盘后/旧数据保留历史提示。
3. 日线：代码/交易所、日期、复权、OHLC有效性、成交量“份/股”、成交额“元”、最后完整交易日；某源没有volume留空，不填零；一只坏标的不拖全池。
4. 指数：上证/沪深300/中证全指真正OHLC；不是ETF代理或重复点数；午夜日期只展示日期粒度。不同市场有不同交易日，不统一比较中国今日。
5. 板块：行业/概念/全市场独立刷新、计数、涨跌幅0不视为缺失；ETF相关性/关键词关联不等于真实成分。
6. 指标/预测：原版模板当前值和前值来自同一版本同一价格口径，列出日期；离线重算不请求SDK或模型；保存旧快照不算刷新成功。无样本/缺量不解除阻断。
7. 新闻：published_at 与 fetched_at 的时区各自核对；未来/无日期待核实；GET状态不抓新新闻，成功采集可能返回旧消息，不能改发布时间。
8. 调度：API/worker/scheduler同版同库；先一次手动→排队→领取→结束→入库→API→页面→重启。仅一套调度、默认关闭BALANCED_REFRESH_ENABLED，之后经确认才开启并观察完整周期。

## 页面与安全

- 唯一总览/详情；保留原版 WorkBuddy模板和路由返回；管理员可读 DataHealth、普通成员直接请求新端点应403；页面读取不POST。
- 图表虚线/辅助线/全屏需截图或trace证明真实绘制，不以DOM出现文字代替。
- AI方式卡片进入既有表单；权限/CSRF/凭据隔离；保存不外呼，模型计费需明确确认，不上传本地auth.json。
- 断网或worker失效时显示缓存日期与明确失败，不因服务health=200判断业务成功。
