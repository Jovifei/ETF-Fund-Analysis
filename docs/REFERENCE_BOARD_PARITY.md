# 公司参考版决策看板复刻与结论统一

本章固定主决策页、信号中心与公司参考看板之间的职责边界，后续 Agent 不得重新引入第二套互相冲突的“当前结论”。

## 1. 唯一当前结论源

当前时点的 ETF 五档结论只有一套：

- 可加仓
- 可入场
- 可试探
- 观望
- 减仓

`DecisionBoardSnapshot.rows[].grade` 是当前展示的 canonical conclusion。

`SignalCenterService` 的机会/风险/止盈前排只是排序和解释视图：

- 机会前排只能来自当前 grade = 可加仓 / 可入场 / 可试探；
- 风险前排来自当前 grade = 观望 / 减仓 / 数据异常；
- 止盈前排仍可使用独立的过热度作为正交提示；
- `SignalSnapshot.state` 继续保留为生产信号历史与曲线依据，但不能覆盖当前 Decision Board grade。

当前状态读取优先级：

1. 最新 `DecisionBoardSnapshot`；
2. 如果尚未生成决策快照，回退到 `SignalGradeService` 的当前五档；
3. 只有前两者都不存在时，才把 `SignalSnapshot.state` 作为最后审计兼容值。

API 保留并区分：当前 `state`、`production_signal_state`、`decision_board_grade`、`signal_grade_fallback` 与 `current_state_source`，从而能解释历史差异而不制造第二套当前结论。

## 2. 参考页技术阈值

主决策页和后端 `SignalGradeService` 使用同一配置：

- KDJ 超买：`J > 100`；
- KDJ 偏高：`90 <= J <= 100`；
- KDJ 低位：`J < 20`；
- `20 <= J < 90` 在无死叉时按健康区展示；
- KDJ 死叉优先于 J 值区间；
- RSI >= 70：超买；
- RSI 50~70：正常偏强；
- RSI 30~50：偏弱；
- RSI < 30：超卖；
- 放量：量比 >= 1.15；
- 平量：0.90 <= 量比 < 1.15；
- 缩量：量比 < 0.90。

后端边界必须和页面文字完全一致，尤其 `J=20` 属于健康、`J=100` 属于偏高、`量比=0.90` 属于平量。

## 3. Quote 与指标百分比单位

`QuoteSnapshot.pct_change` 的持久化合同是 **percentage points**：例如页面上的 `+3.80%` 在 Quote 中是 `3.8`。

进入 `SignalGradeService.classify_row()` 前必须且只能转换一次为 decimal ratio `0.038`。

`IndicatorSnapshot.values_json.return_1d / return_5d` 本身已经是 decimal ratio，不再转换。

这项单位统一是“同一数据源但信号中心和决策看板结论不同”的历史根因之一。

## 4. MACD 显示与分级一致

- 强势金叉：金叉且 DIF > 0；
- 多头延续：DIF > 0 的多头延续；
- 弱势金叉：金叉且 DIF < 0；
- 修复延续：DIF < 0 的多头修复；
- 将叉：弱势区接近金叉；
- 将死叉：多头结构接近死叉；
- 死叉：DIF < DEA / 明确持续空头。

如果展示文案是“死叉”，五档逻辑也必须把它作为减仓风险，不能出现“文字死叉、结论可入场”的自相矛盾。

## 5. 主表必须严格采用 13 个参考列

主页面 `/` 的 ETF 表固定为：

1. 标的
2. 今日涨幅
3. 较昨日
4. 量能
5. 均线多空
6. MACD
7. KDJ
8. 九转
9. RSI
10. 板块涨跌
11. 近1周
12. 明日预测（切换 horizon 后为 3/5/10 日预测）
13. 操作建议

不得在主表重新增加独立的分类、综合分、缠论、数据状态、理由/风险列。这些信息会破坏公司参考页的阅读密度。

综合分保留在“标的”单元格旁的小色块；详细六分项只在点击 ETF 后的详情抽屉展示。缠论、支撑/压力、数据资格、源时间、完整 1/3/5/10 日预测也进入详情层。

## 6. 色彩语义

价格收益采用中国市场习惯：上涨红、下跌绿。

相对方向和均线箭头按公司截图：↑ 绿色、↓ 红色、→ 灰色。

板块宽度：上涨家数绿色、下跌家数红色、跌比灰蓝色。

五档：可加仓绿色、可入场蓝色、可试探金色、观望橙色、减仓红色。

## 7. 页面结构

参考页主结构固定为：

1. 标题、版本、时间、数据源、免责声明；
2. 五档数量卡；
3. 全部 ETF 当日涨跌 ticker；
4. RSI / KDJ / TD / conf / MACD 图例；
5. 筛选与预测周期；
6. 红色“盘中总结”；
7. 五档分组表；
8. 盘中核心变化；
9. 明日/多期限预测解读；
10. 数据来源和指标参数页脚。

## 8. 我们保留的增强能力

公司参考页主表之外，本项目继续保留：

- 多用户 Session / CSRF；
- 每只 ETF 的综合分和六分项解释；
- 点击整行查看历史 K 线；
- 未来研究情景 K 线；
- 支撑位 / 压力位；
- 缠论近似；
- 1 / 3 / 5 / 10 日预测；
- 数据源、源时间与 stale / mock / degraded 降权；
- 用户持仓和完整系统 `/legacy`。

这些能力不得再挤回参考主表核心 13 列。

## 9. 预测口径

`conf` 是历史样本支持度/一致度，不是未来准确率：

- conf >= 60：可参考；
- 40 <= conf < 60：弱信号；
- conf < 40：涨跌接近随机，基本忽略。

`not_calibrated` 必须继续显示，不能因为视觉复刻而隐藏模型未校准事实。

## 10. 安全边界

- 研究系统不自动下单；
- 页面不修改生产持仓；
- Mock / stale / unverified 数据必须降权；
- Signal Center 系数只影响同类排序/止盈研究，不得改变 canonical current grade；
- 页面视觉复刻不得改变未来数据防泄漏、Provider 审计和多用户隔离规则。
