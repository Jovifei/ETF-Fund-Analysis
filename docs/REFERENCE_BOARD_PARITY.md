# 公司参考版决策看板复刻与结论统一

本章固定主决策页、信号中心与公司参考看板之间的职责边界，后续 Agent 不得重新引入第二套互相冲突的“当前结论”。

## 1. 唯一当前结论源

当前时点的 ETF 五档结论只有一套：

- 可加仓
- 可入场
- 可试探
- 观望
- 减仓

`DecisionBoardSnapshot.rows[].grade` 是当前展示的 canonical conclusion。

`SignalCenterService` 的机会/风险/止盈前排只是排序和解释视图：

- 机会前排只能来自当前 grade = 可加仓 / 可入场 / 可试探；
- 风险前排来自当前 grade = 观望 / 减仓 / 数据异常；
- 止盈前排仍可使用独立的过热度作为正交提示；
- `SignalSnapshot.state` 继续保留为生产信号历史与曲线依据，但不能覆盖当前 Decision Board grade。

API 同时暴露：

- `state`: 当前 canonical grade；
- `production_signal_state`: 原 SignalSnapshot 状态；
- `decision_board_grade`: 决策看板 grade；
- `current_state_source`: `decision_board_snapshot` 或无快照时的 `signal_snapshot_fallback`。

这样可以解释历史差异，同时保证用户在同一时点看到的当前方向一致。

## 2. 参考页技术阈值

主决策页和后端 SignalGradeService 使用同一配置：

- KDJ 超买：J > 100；
- KDJ 偏高：90 <= J <= 100；
- KDJ 低位：J < 20；
- 其余在 K>=D 且无死叉时按健康区展示；
- KDJ 死叉优先于 J 值区间；
- RSI >= 70：超买；
- RSI 50~70：正常偏强；
- RSI 30~50：偏弱；
- RSI < 30：超卖；
- 放量：量比 >= 1.15；
- 平量：0.9 <= 量比 < 1.15；
- 缩量：量比 < 0.9。

量能阈值已从旧的 1.35 / 0.85 调整为公司参考规格 1.15 / 0.90，并升级 `signal_grade_version`。

## 3. 主表必须严格采用 13 个参考列

主页面 `/` 的 ETF 表固定为：

1. 标的
2. 今日涨幅
3. 较昨日
4. 量能
5. 均线多空
6. MACD
7. KDJ
8. 九转
9. RSI
10. 板块涨跌
11. 近1周
12. 明日预测（切换 horizon 后为 3/5/10 日预测）
13. 操作建议

不得在主表重新增加独立的：

- 分类列；
- 综合分列；
- 缠论列；
- 数据状态列；
- 理由/风险列。

这些信息会破坏公司参考页的阅读密度。

综合分仍然保留，但缩成“标的”单元格旁的彩色小徽标；详细六分项只在点击 ETF 后的详情抽屉展示。

缠论、支撑/压力、数据资格、源时间、完整 1/3/5/10 日预测也进入详情层。

## 4. 色彩语义

价格收益采用中国市场习惯：

- 上涨：红色；
- 下跌：绿色。

相对方向和均线箭头按公司截图：

- ↑：绿色；
- ↓：红色；
- →：灰色。

板块宽度：

- 上涨家数：绿色；
- 下跌家数：红色；
- 跌比：灰蓝色。

五档：

- 可加仓：绿色；
- 可入场：蓝色；
- 可试探：金色；
- 观望：橙色；
- 减仓：红色。

## 5. 页面结构

参考页主结构固定为：

1. 标题、版本、时间、数据源、免责声明；
2. 五档数量卡；
3. 全部 ETF 当日涨跌 ticker；
4. RSI / KDJ / TD / conf / MACD 图例；
5. 筛选与预测周期；
6. 红色“盘中总结”；
7. 五档分组表；
8. 盘中核心变化；
9. 明日/多期限预测解读；
10. 数据来源和指标参数页脚。

## 6. 我们保留的增强能力

公司参考页的主表外，本项目继续保留：

- 多用户 Session / CSRF；
- 每只 ETF 的综合分和六分项解释；
- 点击整行查看历史 K 线；
- 未来研究情景 K 线；
- 支撑位 / 压力位；
- 缠论近似；
- 1 / 3 / 5 / 10 日预测；
- 数据源、源时间与 stale / mock / degraded 降权；
- 用户持仓和完整系统 `/legacy`。

这些能力不得再挤回参考主表的核心 13 列。

## 7. 预测口径

`conf` 是历史样本支持度/一致度，不是未来准确率：

- conf >= 60：可参考；
- 40 <= conf < 60：弱信号；
- conf < 40：低参考价值。

`not_calibrated` 必须继续显示，不能因为页面复刻而隐藏模型未校准事实。

## 8. 安全边界

- 研究系统不自动下单；
- 页面不修改生产持仓；
- Mock / stale / unverified 数据必须降权；
- Signal Center 系数只影响其排序/研究视图，不得改变 canonical current grade；
- 页面视觉复刻不得改变未来数据防泄漏、Provider 审计和多用户隔离规则。
