# ETF 决策看板：评分台与信号分级合并规范

## 目标

`/` 不再同时存在“ETF 决策评分卡片页”和“ETF 信号分级表格页”两套主视图。

主页面必须以截图式的 **一只 ETF 一行** 为核心：

- 第一层：后端五档分级 `可加仓 / 可入场 / 可试探 / 观望 / 减仓`；
- 第二层：读取层综合分，用于同一档位内部观察多指标一致程度；
- 第三层：一行内直接解释量能、MA、MACD、KDJ、TD9、RSI、板块宽度、近 1 周和预测；
- 点击整行后才进入 K 线、支撑/压力、未来研究情景和六分项评分详情。

综合分不得覆盖后端五档分级，不得被解释为上涨概率或历史准确率。

## 主表固定列

1. 标的：名称、代码、行业/主题、数据源与源时间；
2. 综合分：0–100 读取层评分与颜色；
3. 今日涨幅；
4. 较昨日；
5. 量能；
6. 均线多空；
7. MACD；
8. KDJ；
9. 九转（当前仅 TD9 setup）；
10. RSI；
11. 板块涨跌；
12. 近 1 周（5 个交易日）；
13. 明日 / 3 日 / 5 日 / 10 日预测（由页面周期切换）；
14. 操作建议（后端五档分级原样显示）。

## 色彩语义

与现有参考截图保持一致：

- 行情收益：红涨、绿跌；
- `较昨日`、MA 方向：向上为绿、向下为红；
- 板块家数：上涨家数绿、下跌家数红；
- 可加仓：绿色；可入场：蓝色；可试探：金色；观望：橙色；减仓：红色；
- MACD/KDJ/TD 等状态使用紫、青、橙、红、绿等高辨识度标签，不做黑白表格。

## KDJ J 值显示规则

- `J > 100`：超买/钝化，回撤风险高；
- `90 <= J <= 100`：偏热，不追高；
- `70 <= J < 90`：偏强，仍有余量；
- `30 <= J < 70`：健康区；
- `10 <= J < 30`：低位，等待拐头；
- `J < 10`：极低/超卖，但不等于立即买入；
- KDJ 死叉优先降分。

## 综合分口径

读取层权重：

- 趋势 22%；
- 动量 22%；
- 量能 14%；
- 结构 14%；
- 预测 20%；
- 数据资格 8%。

Mock、陈旧、退化、未验证源时间会降低数据资格分。

## 保留能力

- `/legacy`：完整旧系统；
- `/workbench/kline`：K 线企稳研究页；
- 点击 `/` 任一 ETF 行：打开历史 K 线 + 未来研究情景 + 支撑压力 + 1/3/5/10 日预测详情；
- 多用户 Session Cookie + CSRF 登录继续生效；
- 页面不保存密码或 Bearer Token。

## 工程边界

本次仅合并展示和读取层评分逻辑，不改变 `SignalGradeService.assign_grade()` 的五档生产研究分级规则，不自动下单，也不将 `not_calibrated` 预测包装成已校准概率。
