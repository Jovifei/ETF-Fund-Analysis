# ETF 决策看板：统一主视图规范

> 视觉与指标解释的详细规则以 `docs/REFERENCE_BOARD_PARITY.md` 为最终权威。本文件只固定“评分台 + 分级看板”的合并边界，避免后续重新拆成两套页面。

## 目标

主页面 `/` 只有一套当前 ETF 决策视图：

- 一只 ETF 一行；
- 第一层是 canonical 五档分级：`可加仓 / 可入场 / 可试探 / 观望 / 减仓`；
- 综合分只作为标的名称旁的小色块，解释多指标共振程度；
- 点击整行后才进入 K 线、未来研究情景、支撑/压力、缠论近似和六分项评分详情。

综合分不得覆盖五档分级，不得被解释为上涨概率或历史准确率。

## 主表固定 13 列

1. 标的（名称、代码/主题；综合分为行内小徽标）
2. 今日涨幅
3. 较昨日
4. 量能
5. 均线多空
6. MACD
7. KDJ
8. 九转
9. RSI
10. 板块涨跌
11. 近 1 周
12. 明日预测（切换 horizon 后为 3/5/10 日预测）
13. 操作建议

不得重新增加独立的：分类列、综合分列、缠论列、数据状态列、理由/风险列。这些信息进入标的副文本或详情层。

## 当前结论唯一来源

最新 `DecisionBoardSnapshot.rows[].grade` 是当前时点 canonical conclusion。

信号中心：

- 当前机会/风险成员必须读取同一份 DecisionBoardSnapshot；
- 尚无 DecisionBoardSnapshot 时，优先使用 `SignalGradeService` 当前五档作为 fallback；
- `SignalSnapshot.state` 只作为生产历史审计和历史曲线依据，不得覆盖当前五档；
- 信号系数只影响同类排序和止盈热度，不得创造第二套当前机会/风险成员。

## 公司参考技术阈值

KDJ：

- `J > 100`：超买；
- `90 <= J <= 100`：偏高；
- `20 <= J < 90`：健康（无死叉时）；
- `J < 20`：低位；
- KDJ 死叉优先于 J 区间。

RSI：

- `RSI >= 70`：超买；
- `50 <= RSI < 70`：正常偏强；
- `30 <= RSI < 50`：偏弱；
- `RSI < 30`：超卖。

量能：

- 放量：`>= 1.15`；
- 平量：`0.90 <= ratio < 1.15`；
- 缩量：`< 0.90`。

conf：

- `>=60`：可参考；
- `40~60`：弱信号；
- `<40`：基本忽略。

## 色彩语义

- 收益：红涨、绿跌；
- `较昨日` / MA 方向：↑ 绿色、↓ 红色、→ 灰色；
- 板块：上涨家数绿、下跌家数红；
- 五档：可加仓绿、可入场蓝、可试探金、观望橙、减仓红；
- MACD / KDJ / TD 使用高辨识状态标签。

## 综合分

读取层六项：趋势 22%、动量 22%、量能 14%、结构 14%、预测 20%、数据资格 8%。

它只用于解释和同档观察。Mock、陈旧、退化、未验证源时间会降低数据资格分。

## 保留能力

- `/legacy`：完整多用户系统；
- `/workbench/kline`：K 线企稳研究页；
- 点击 ETF 行：历史 K 线、未来研究情景、支撑/压力、缠论近似、1/3/5/10 日预测；
- 多用户 Session Cookie + CSRF；
- 持仓、OCR、新闻、系统设置等仍在完整系统中。

## 安全边界

不自动交易、不连接券商、不创建订单；`not_calibrated` 必须继续显示；视觉复刻不得削弱数据源审计、未来数据防泄漏、多用户隔离或 Mock/stale/unverified 降权。
