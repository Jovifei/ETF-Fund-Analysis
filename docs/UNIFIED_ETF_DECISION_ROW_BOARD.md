# ETF 决策看板：公司参考版统一规范

## 唯一当前结论源

主页面 `/` 与旧系统里的“信号中心”不得再各自产生一套当前结论。

当前结论统一为最新 `DecisionBoardSnapshot` 中的五档分级：

- 可加仓
- 可入场
- 可试探
- 观望
- 减仓

`SignalCenterService` 当前机会/风险成员直接读取同一份 DecisionBoardSnapshot；如果数据库尚无决策快照才回退到 `SignalGradeService`。`SignalSnapshot.state` 只保留为生产历史审计字段 `production_state`，不允许覆盖主看板当前五档。

信号中心的系数只用于同类前排排序和止盈热度，不得改变当前机会/风险成员归属。历史曲线仍保留旧 `SignalSnapshot` 历史口径，并必须明确标记为 legacy history。

## 公司参考页面结构

视觉和信息层级以项目收到的公司参考看板为规格，主页面按下列顺序组织：

1. 标题、标的数量、数据来源、免责声明、快照时间；
2. 五档数量摘要；
3. 全部标的今日涨跌横条；
4. RSI / KDJ / TD / conf / MACD / MA / 量能图例；
5. 红色“盘中总结”；
6. 五档分组表格；
7. “盘中核心变化”；
8. “明日/3日/5日/10日预测”；
9. 数据源、技术指标和预测口径脚注。

不再使用“一只 ETF 一张大卡片”的主页面结构。

综合分不得覆盖五档分级，不得解释为上涨概率或历史准确率。

## 五档文案

- 可加仓：`J<90 · 上涨放量 · MA多头排列`
- 可入场：`J<90 · KDJ有余量 · 结构向好`
- 可试探：`J<90 · 信号偏弱 · 结构尚可`
- 观望：`超买/偏高 · 放量滞涨 · 回调风险`
- 减仓：`KDJ死叉 · MACD将死叉 · 多重看空共振`

数据异常不是正常第六档；只有实际存在异常标的时才额外显示异常区。

## 颜色语义

- 行情收益：红涨、绿跌；
- `较昨日` 和 MA 方向：向上绿、向下红；
- 板块家数：上涨家数绿、下跌家数红；
- 可加仓绿色、可入场蓝色、可试探金色、观望橙色、减仓红色；
- MACD / KDJ / TD 状态使用青、紫、橙、红、绿等高辨识标签；
- `conf` 使用金黄色弱化显示。

## KDJ J 值规则

后端与前端必须完全一致：

- `J > 100`：超买 · 短期过热 · 回调风险高；
- `90 <= J <= 100`：偏高 · 动能偏强 · 谨慎追高；
- `20 <= J < 90`：健康 · 趋势健康 · 可观察；
- `J < 20`：低位 · 超卖 · 反弹概率升高；
- KDJ 死叉优先于 J 区间，显示空头风险。

## RSI 规则

- `RSI >= 70`：超买 · 短期回调风险高；
- `50 <= RSI < 70`：正常偏强 · 趋势中段；
- `30 <= RSI < 50`：偏弱 · 动能不足；
- `RSI < 30`：超卖 · 反弹概率升高。

## 量能规则

- 放量：`量比 >= 1.15`；
- 平量：`0.90 <= 量比 < 1.15`；
- 缩量：`量比 < 0.90`。

## 预测置信度显示

`conf` 只表示当前历史相似样本支持程度，不是胜率：

- `conf >= 60`：可参考；
- `40 <= conf < 60`：弱信号；
- `conf < 40`：不确定性高，基本忽略。

`not_calibrated` 必须继续保留，不得包装成真实准确率。

## MACD 显示文案

- 强势金叉：金叉且 DIF > 0；
- 多头延续：DIF > 0 的多头延续；
- 弱势金叉：金叉且 DIF < 0；
- 修复延续：DIF < 0 的多头修复；
- 将叉：弱势区域接近金叉；
- 将死叉：多头结构接近死叉；
- 死叉：DIF < DEA / 明确空头结构。

“死叉”显示必须同时属于减仓风险，不能出现文字写“死叉”但分级仍为可入场/可试探。

## Quote 百分比单位

`QuoteSnapshot.pct_change` 的持久化合同是 percentage points，例如 `+3.80`；进入分级算法前必须且只能转换一次为 decimal ratio `0.038`。指标快照的 `return_1d/5d` 已经是 decimal ratio，不再次转换。

这是过去信号中心和决策看板可能出现不同结果的一个关键修复点。

## 综合分

读取层六项权重仍为：

- 趋势 22%；
- 动量 22%；
- 量能 14%；
- 结构 14%；
- 预测 20%；
- 数据资格 8%。

Mock、陈旧、退化或未验证源时间会降低数据资格分。综合分只用于解释与同档观察，不改变五档成员。

点击任一 ETF 行仍进入详情：

- 历史 K 线；
- 未来研究情景 K 线；
- 支撑 / 压力；
- 缠论近似；
- 六项综合评分；

`/legacy` 继续保留完整系统、多用户登录、持仓、OCR、新闻、系统设置和信号中心。

## 工程边界

- 多用户 Session Cookie + CSRF 不变；
- 不自动交易、不连接券商、不创建订单；
- 不让 LLM 计算技术指标或预测数值；
- 页面必须使用同一 DecisionBoardSnapshot 展示主结论；
- SignalSnapshot 生产状态只作审计，不允许再成为第二套当前结论。
