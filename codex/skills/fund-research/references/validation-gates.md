# 验证门槛

## 预测

- 时间顺序切分；
- 每个期限独立评估；
- 输出 Brier、方向准确率、MAE、区间覆盖率和校准桶；
- 至少包含上涨、震荡和下跌市场状态；
- 与恒定 50% 和历史均值基准比较；
- 不因单一高收益区间封版。

## 组合

- 向量化粗筛；
- 事件驱动审计；
- T+1、整手、费用、滑点、停牌和无法成交；
- 组合权重、现金、市场门控、主题上限、迟滞；
- 训练、滚动、Holdout；
- 对齐误差有解释。

## 发布

- 测试通过；
- 版本和 input hash 完整；
- 数据源不是 Mock；
- 实时/退化状态明确；
- 人工批准。
