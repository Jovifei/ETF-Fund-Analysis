# 沪深300 头部基金市值占流通市值比例：研究接入设计

日期：2026-10-28；状态：RESEARCH_DESIGN，未实现计算，未进入评分。

## 1. 指标精确定义

建议名称：`hs300_passive_share_of_float_mv`（流通市值口径）。若将来采用自由流通口径，另立 `hs300_passive_share_of_free_float_mv`，两者不得混用。

```
分子 = Σ（被定义为「头部」的沪深300 跟踪基金的基金市值；AUM 与市值须显式标注）
分母 = 沪深300 指数样本股的流通市值合计（float market cap）
比例 = 分子 / 分母
```

口径已按 Jovi 的原话「流通市值」校准；数据源选型见 `2026-10-29-hs300-ratio-data-source-selection.md`。

约束：

- 「头部」定义为全部跟踪沪深300 的 ETF（2026-10-29 决定）；排除联接基金、LOF 与增强指数基金。运行期只读冻结的配置清单，每次计算携带清单哈希与候选数。
- 分子用基金资产净值，不用场内成交额、不用份额变化、不用 ETF 收盘价乘份额冒充净值；若只能取得份额，必须标注为「份额代理」并单独命名。
- 分母必须是同一交易日、同一指数、同一流通口径；总市值、上证流通市值、成交额都不能替代。
- 联接基金与其目标 ETF 不得重复计入；场外指数基金、增强指数基金是否计入必须在配置中显式声明。
- 比例必须带 `as_of`、分子/分母各自来源、披露滞后天数（ETF 份额通常 T+1 完整）。

## 2. 为什么有信息量（以及不是什么）

可用作研究上下文的三类解释：

1. **被动资金占比**：头部 ETF 规模 / 指数可交易盘子，反映被动配置在该指数中的存量权重。
2. **增量申购强度**：比例的 N 日变化，比绝对水平更能反映近期申购/赎回方向。
3. **拥挤度观察**：比例处于自身历史高分位时，指数对被动赎回和拥挤反转更敏感。

它不是：

- 不是买卖点。比例高不等于马上跌，比例低不等于马上涨。
- 不是资金流。份额增加可能是套利、做市或申赎，不等于主动看多。
- 不是实时指标。份额与净值披露有滞后，不能当日内信号。

## 3. 当前数据缺口（2026-10-28 实测）

| 输入 | 现状 | 结论 |
|---|---|---|
| 基金份额 | `providers/share_scale.py` 已有 SSE/SZSE 份额接口，`EtfShareScale` 已持久化 | 可得，但只覆盖已配置基金 |
| 基金净值/规模 | 无基金净值序列；可用份额 × 场内价格作代理，但需单独命名 | 只能先做代理 |
| 沪深300 流通市值 | AKShare 指数接口只有 OHLC、成交额、滚动市盈率；`stock_zh_index_value_csindex` 只有市盈率/股息率 | AKShare 不可得；Tushare `daily_basic` + `index_weight`（2000 积分）可回填，详见选型文档 |
| 成分股流通市值 | 可通过成分股列表 + 全市场快照汇总，但这是「流通市值合计」，不是指数自由流通市值；300 只逐日抓取还需新的准入与存储 | 新数据源，需专项准入 |

因此：**今天不能诚实地算出这个比例**。任何用总市值、成交额或单只 ETF 规模替代分母的实现，都会把口径错误带进决策，按项目规则必须拒绝。

## 4. 最小接入形态（未来实现时）

1. 新增只读研究视图，计算函数为纯函数，输入为两条已校验序列：
   - `numerator`: `[{trade_date, value, source, source_timestamp, lag_days}]`
   - `denominator`: `[{trade_date, value, source, source_timestamp, lag_days, basis}]`
2. 任一序列缺失、日期不一致、来源未准入、`basis` 不是 `float_market_cap`（自由流通变体必须单独命名）→ 返回 `status=unavailable` 与固定 reason code，不返回数字。
3. 输出固定字段：`ratio`、`numerator`、`denominator`、`as_of`、`lag_days`、`fund_count`、`universe_hash`、`fund_codes`、`source`、`actionable=false`、`research_only=true`、`changes_grade=false`、`qualification=UNKNOWN`、`calibration_status=not_calibrated`。
4. 只进入详情页的研究上下文，不进入 `SignalService` 打分、不改变 `state`、不改变仓位建议。
5. 分母数据源必须先通过 provider 准入（来源、许可、单位、时间口径、可复现证据），再新增持久化快照；不得在业务代码中写死网页接口。

## 5. 验证设计（进入评分前的门槛）

- 序列至少覆盖一个完整牛熊周期或不少于 3 年；样本不足时只展示，不校准。
- 事件定义：比例的 20 日变化处于自身历史分位 P90/P10，持有期 5/20/60 日。
- 对照：同一区间沪深300 自身收益；必须报告胜率、均值差、最大回撤差与样本数。
- 必须做 walk-forward：训练窗口只用事件发生前的数据，禁止未来函数；重叠标签要按 horizon 做 purge。
- 失败条件：任一持有期相对基准无稳定优势、样本数不足、换一个 top_n 就反转 → 结论为「不进入评分」，保留研究展示。
- 人工批准记录与报告哈希纳入 `qualification_gate` 风格的门槛；未批准前 `actionable` 永远为 false。

## 6. 非目标

- 不在本轮改指标公式、信号权重、仓位阈值。
- 不启用自动交易。
- 不用 LLM 计算该比例或替代数值验证。
- 不把「比例处于高位」直接翻译成减仓。
